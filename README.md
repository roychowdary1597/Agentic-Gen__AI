# 🚀 Generative AI & Agentic AI Projects Repository

This repository contains all essential projects, modules, and resources for learning and building with **Generative AI**, **Large Language Models (LLMs)**, and **Agentic AI systems**.

It is organized to help you progress from foundational concepts to building full end-to-end autonomous AI agents.

---

## 📘 Overview

This repository includes:

### **1. Fundamentals of Generative AI & LLMs**

Learn how modern AI systems generate text, reason about tasks, and make decisions.
Includes basic concepts such as tokenization, embeddings, transformers, and model capabilities.

### **2. Prompt Engineering**

Explore techniques for crafting clear, effective prompts.
Learn how small changes in phrasing can dramatically improve AI responses and reasoning.

### **3. Agentic AI Systems**

Build systems that can think, reason, plan actions, and operate autonomously.
Covers structured workflows, tool use, and multi-agent coordination.

---

## 🧩 Frameworks Covered

This repository includes modules and projects built using:

* **N8N** – Workflow automation with AI logic
* **LangChain** – RAG, agents, memory, and LLM pipelines
* **LangGraph** – Reasoning workflows and agentic state management
* **LangSmith** – Debugging, tracing, and evaluating AI systems
* **CrewAI** – Multi-agent collaboration and task coordination
* **LangServe** – Deploying AI applications into production environments
